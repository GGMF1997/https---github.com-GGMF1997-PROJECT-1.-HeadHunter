# Проект: Анализ резюме из HeadHunter

Анализ базы резюме, выгруженной с сайта [HeadHunter](https://hh.ru).  
Учебный проект по исследованию данных, преобразованию признаков, визуализации и очистке данных.

---

## Описание проекта

В работе проводится полный цикл анализа данных резюме:

### 1. Исследование структуры данных
- Загрузка датасета
- Просмотр первых строк и типов данных
- Анализ пропусков
- Базовые описательные статистики

### 2. Преобразование данных
- Выделение уровня образования из текстового признака
- Разделение признака «Пол, возраст» на отдельные столбцы `Пол` и `Возраст`
- Преобразование опыта работы в месяцы
- Выделение города, готовности к переезду и командировкам
- One-Hot Encoding признаков «Занятость» и «График»
- Перевод желаемой зарплаты в рубли с учётом курсов валют

### 3. Исследовательский анализ данных
- Распределение соискателей по полу, возрасту, образованию, городам
- Анализ зависимости зарплаты от различных факторов
- Визуализация ключевых закономерностей

### 4. Очистка данных
- Удаление полных дубликатов
- Обработка пропусков
- Удаление выбросов по зарплате
- Удаление логических ошибок (опыт работы больше возраста)
- Поиск выбросов по возрасту методом z-оценки

## Данные

Исходный файл `hh_database.csv` весит более 450 МБ, поэтому **не хранится** в репозитории.

**Скачать данные:**  
[Ссылка на Google Диск](https://drive.google.com/drive/folders/1VwhlerZ9Edn22KbIs7dASku3wHn8Neku?dmr=1&ec=wgc-drive-%5Bmodule%5D-goto)

После скачивания поместите файл в папку `data/`:

```text
проект/
├── data/
│   └── hh_database.csv
├── plots/
├── Project-1._Ноутбук-шаблон.ipynb
├── .gitignore
└── README.md
```

## Структура проекта

| Файл / папка                          | Описание                                      |
|---------------------------------------|-----------------------------------------------|
| `Project-1._Ноутбук-шаблон.ipynb`     | Основной ноутбук с полным анализом            |

## Как запустить

1. Скачайте файл данных по ссылке выше.
2. Создайте папку `data/` и положите туда `hh_database.csv`.
3. Откройте ноутбук `Project-1._Ноутбук-шаблон.ipynb`.
4. Запустите все ячейки по порядку.

## Основные выводы (кратко)

- Большинство соискателей — мужчины (~81 %).
- Средний возраст соискателей ≈ 32 года.
- Около 75 % имеют высшее образование.
- Значительная часть резюме из Москвы.
- Обнаружены и удалены выбросы: слишком высокие/низкие зарплаты, логические ошибки в опыте работы, аномально маленький возраст.
